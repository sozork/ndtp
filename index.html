Про сайт


Страница показывает сравнение погрешностей в предсказании погоды по сайтам yandex и api google. Почему не использовать api yandex? Потому что пользовательское соглашение яндекса не позволяет сохранять данные, а тут это важно. Так что из-за способа получения информации могут быть сильные погрешности. Данные потом сравниваются с историей опенметио https://open-meteo.com/en/docs


Слайдер сверху "последних дней показывает", контролирует предсказания на сколько последних дат показывать, т.е не дату когда предсказание было записано, а дату, на которую оно было сделано
